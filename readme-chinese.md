# NEXUS TAURUS 操作系统

**具备数字孪生架构的实时机器人操作平台**

> 用于自主车辆操作、遥测管理和任务控制的专业地面控制基础设施。

---

## 概述

NEXUS TAURUS 操作系统(NTO)是一个生产级机器人操作平台,设计用于:

- 从实体车辆**实时遥测数据接入**
- **数字孪生同步**,镜像实际车辆状态
- 带验证和确认的**指挥与控制**
- 具有完整遥测持久化的**任务日志记录**
- 通过 SASHA(呼号:Ghost)实现**AI 驱动的任务控制**
- 用于多车辆车队操作的**可扩展架构**

这不是模拟。这是真实的硬件操作基础设施。

## 快速开始

### 前置要求

- **Python 3.11+** (地面站)
- **Node.js 18+** (前端)
- **PlatformIO** (固件开发)
- 配备 ESP32-S3 的 **Yahboom G1 坦克**

### 地面站设置

```bash
cd ground_station/backend
python -m venv .venv
.venv\Scripts\activate  # Windows
pip install -e .
nto-server run
```

### 固件上传

```bash
cd firmware/taurus_01
pio run --target upload
```

### 前端开发

```bash
cd ground_station/frontend
npm install
npm run dev
```

## 遥测协议

所有车辆到地面的通信通过 WebSocket 使用结构化 JSON 协议:

```json
{
  "msg_type": "telemetry",
  "vehicle_id": "TAURUS-01",
  "timestamp": 1705632000000,
  "sequence": 12345,
  "payload": {
    "position": {"x": 0.0, "y": 0.0, "heading": 90.0},
    "velocity": {"linear": 0.5, "angular": 0.0},
    "battery": {"voltage": 7.4, "current": 1.2, "percent": 85},
    "motors": {"left": 128, "right": 128},
    "sensors": {"ir_left": 1, "ir_right": 1, "ultrasonic": 45.2}
  }
}
```

命令遵循相同结构并带有确认:

```json
{
  "msg_type": "command",
  "command_id": "cmd_001",
  "vehicle_id": "TAURUS-01",
  "command": "MOVE",
  "params": {"linear": 0.5, "angular": 0.0}
}
```

## 开发标准

- **所有代码**必须包含类型提示(Python)或 TypeScript
- **所有业务逻辑函数**需要单元测试
- **遥测**是不可变的 - 仅追加日志记录
- **命令**在状态更改之前需要确认
- **Git 提交**遵循常规提交格式
